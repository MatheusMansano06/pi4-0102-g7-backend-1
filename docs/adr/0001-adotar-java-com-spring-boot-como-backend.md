# ADR 0001: adotar Java com Spring Boot como backend

**Status:** aceito

**Contexto:** O ArchFlow precisa de um backend para atender às funcionalidades do sistema, como o gerenciamento de solicitações, usuários, estoque e status dos pedidos. Para o desenvolvimento dessa parte do projeto, foi definida a utilização de Java e é necessário utilizar uma tecnologia que auxilie na criação e organização do backend.

**Decisão:** Adotar Java com Spring Boot para desenvolver o backend do ArchFlow.

**Alternativas consideradas:**
- Node.js: descartado porque o grupo definiu Java como linguagem para o backend.

**Consequências:**
- Positivas: facilita o desenvolvimento do backend e permite organizar as funcionalidades do sistema de forma estruturada.
- Negativas: será necessário revisar conceitos e a utilização dos recursos do Spring Boot durante o desenvolvimento, além de lidar com suas configurações e dependências.
